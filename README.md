# 🚗 Car Collision Detection using Computer Vision

A computer vision-based system that processes real-time or recorded traffic footage to detect road anomalies and identify potential or actual car collisions. This project utilizes object detection, object tracking, and collision analysis to monitor traffic behavior and enhance road safety.

## 🚀 Features

- Real-time video processing from CCTV/traffic cameras
- Over 2000 Frames per Video extracted and preprocessed using OpenCV.
- Object detection using YOLOv8.
- Collision detection using:
  - Bounding box intersection (IoU)
  - Speed drop analysis
  - Motion trajectory overlap
